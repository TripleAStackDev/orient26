1. Core IT Systems

These systems help students manage their studies, access learning resources and complete academic tasks at TAMK.

  • Pakki
    Pakki is the TAMK student information system. It is used for course registration, checking grades and accessing other academic information.
  • Tuudo
    Tuudo is a mobile application that provides access to student services and information, including schedules, campus maps, student discounts and notifications.
  • Microsoft 365
    Microsoft 365 includes productivity tools such as Word, Excel, PowerPoint and OneDrive. Students can use these tools for assignments, presentations, spreadsheets and cloud storage.
  • TAMK Cloud GitLab
    GitLab is a web-based platform for version control and collaboration. Students can manage code repositories, track changes and work on programming projects.
  • TAMK Linux Systems
    These instructions provide information about Linux computing environments. Linux is useful for programming, command-line operations and software development in my Software Engineering studies.

2. External Tools and Resources

In addition to TAMK's core systems, other digital services can make studying and accessing educational resources easier.

  • HAKA
    HAKA is a federated authentication service that allows users to access participating digital services using their home institution's credentials. This reduces the need to manage separate login details for every supported service.
